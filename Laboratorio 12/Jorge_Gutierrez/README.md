# Laboratorio 12 - Jorge Gutierrez

## Proyecto: CampusMotion

### Descripción
CampusMotion es una página web desarrollada con HTML5 y CSS3 que presenta una agenda de tres talleres universitarios.

El proyecto implementa animaciones CSS, transiciones, controles de reproducción y características de accesibilidad.

### Tecnologías utilizadas
- HTML5
- CSS3
- CSS Grid
- Animaciones CSS (@keyframes)
- Transiciones CSS
- Media Queries

### Funcionalidades
- Tres tarjetas de talleres.
- Animaciones de entrada escalonadas.
- Indicador decorativo con movimiento repetitivo.
- Controles para activar y pausar animaciones.
- Efectos al pasar el cursor y utilizar el teclado.
- Diseño adaptable a diferentes tamaños de pantalla.
- Compatibilidad con preferencias de movimiento reducido.

Guia de laboratorio 12/

- css/
  - styles.css

### Ejecución
Abrir el archivo index.html en un navegador web.
