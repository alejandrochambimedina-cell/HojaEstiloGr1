# TecnoStore - Proyecto de trabajo en equipo

## Estructura del proyecto

- Inicio: página principal.
- Computadoras: catálogo de computadoras.
- Gaming: página asignada al integrante responsable de Tailwind CSS.
- Componentes: página asignada al integrante responsable de Materialize CSS.
- Electrodomesticos: página asignada al integrante responsable de Material Design.
- Carrito: trabajo correspondiente al carrito de compras.
- Recursos: archivos compartidos del proyecto.

## Recursos compartidos

- CSS/: hojas de estilos compiladas.
- SCSS/: archivos fuente de SASS.
- JS/: JavaScript compartido.
- Imagenes/: imágenes del proyecto.

## Reglas de trabajo

1. Cada integrante debe trabajar dentro de su carpeta asignada.
2. No modificar los archivos de otros integrantes sin coordinación.
3. No reemplazar los recursos compartidos sin autorización.
4. Cada página debe organizar sus propios estilos y scripts.
5. Evitar cargar frameworks innecesarios en páginas ajenas.
6. Antes de integrar cambios, comprobar que la página funcione.
7. Trabajar en ramas independientes y realizar Pull Requests para integrar cambios.

## Importante

Los recursos compartidos deben mantenerse organizados y las rutas
de los archivos HTML deben apuntar a la carpeta Recursos.
