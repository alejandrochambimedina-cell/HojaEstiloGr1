    Sobre Bootstrap

    Bootstrap es un framework de código abierto de CSS y JavaScript creado en Twitter (lanzado en 2011). Ofrece una grilla responsive de 12 columnas, componentes ya armados (barra de navegación, tarjetas, modales, formularios, alertas) y clases de utilidad para construir interfaces sin escribir el CSS desde cero.

    • Desarrollo rápido: los componentes ya vienen diseñados y probados.
    • Responsive y mobile-first desde el primer momento.
    • Documentación enorme y comunidad muy activa.
    • Consistencia visual entre las páginas y entre los integrantes del equipo.
    • Componentes con JavaScript incluido (menú colapsable, modales, toasts, acordeones).
    • Personalizable con variables CSS y con Sass.

    • Prototipos y productos mínimos viables.
    • Paneles de administración y dashboards.
    • Sitios institucionales y páginas de aterrizaje.
    • Proyectos de equipo que necesitan un estándar visual común.

    En esta página: barra de navegación con menú colapsable (navbar), grilla row-cols, tarjetas (card), campo de búsqueda (input-group), botones agrupados (btn-group), selector (form-select), insignias (badge), acordeón (esta ficha) y notificación (toast).

    Fuera del proyecto: tiendas en línea, sitios corporativos y paneles internos. Ojo: sin personalizar, los sitios hechos con Bootstrap tienden a parecerse entre sí.
