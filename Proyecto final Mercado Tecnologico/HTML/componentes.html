    Sobre Tailwind CSS

    Definición

    Tailwind CSS es un framework utility-first: en lugar de componentes ya armados, ofrece miles de clases pequeñas (flex, p-4, text-center, hover:bg-blue-600) que se combinan directamente en el HTML para construir cualquier diseño. Lo creó Adam Wathan (2017) y su versión 4 (2025) se configura desde el propio CSS con un motor nuevo y más rápido.

    Ventajas

    • Diseños a medida sin salir del HTML ni inventar nombres de clases.
    • En producción solo se incluye el CSS que realmente usas: archivos muy livianos.
    • Responsive y estados con prefijos (md:, hover:, dark:).
    • Escala de espaciados, colores y tamaños consistente.
    • Encaja muy bien con componentes de React, Vue o Astro.

    Usos

    • Interfaces con identidad visual propia.
    • Sistemas de diseño y librerías de componentes.
    • Aplicaciones con frameworks de JavaScript.
    • Prototipos rápidos de pantallas personalizadas.

    Aplicaciones

    En esta página: el diseño completo (tarjetas con ficha técnica, barra de filtros, efectos al pasar el mouse y menú móvil) sale de clases utilitarias escritas en el HTML. Lo único de CSS propio es el carrito, el pago y la notificación, que comparte todo el sitio.

    Fuera del proyecto: aplicaciones web, tiendas y páginas de producto. Ojo: el HTML se llena de clases y cuesta memorizarlas al inicio. Aquí se usa el script de navegador por simplicidad; en producción se compila con la herramienta de línea de comandos o con Vite.
