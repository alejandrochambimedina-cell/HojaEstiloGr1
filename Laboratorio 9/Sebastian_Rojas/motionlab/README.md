# MotionLab Talleres · Semana 9 (Animaciones CSS)

Catálogo responsivo con entradas escalonadas (`card-enter`) e indicador decorativo (`indicator-rise`),
controlados con dos casillas nativas (sin JavaScript) y respetando `prefers-reduced-motion`.

## Ejecutar
No hay dependencias ni build. Abre la carpeta en VS Code y usa **Live Server** sobre `index.html`
(o `npx serve .`).

## Estructura
- `index.html` — contenido, controles y tarjetas
- `css/styles.css` — base, componentes, fotogramas y controles
- `evidencias/` — capturas y matriz de pruebas
