Guía de Laboratorio 11: MotionLab 11

Estudiante: Jorge Gutierrez
Tema: Compatibilidad entre navegadores con CSS.

Objetivo

Desarrollar una página web que utilice CSS moderno y comprobar su funcionamiento en distintos navegadores.

Estructura del proyecto

Guia de laboratorio 11/index.html: estructura y contenido de la página.

Guia de laboratorio 11/css/styles.css: estilos, diseño adaptable y mejoras progresivas.

Características implementadas

Diseño con tarjetas y estilos base.

Uso de @supports para comprobar compatibilidad con propiedades CSS.

Uso de color-mix() como mejora visual.

Animaciones y consideración de prefers-reduced-motion.

Estilos alternativos para mantener una presentación básica cuando ciertas funciones no están disponibles.

Pruebas realizadas

Se comprobó la página en Google Chrome y Microsoft Edge. También se verificó mediante CSS.supports() el soporte de display: grid y color-mix() en el navegador utilizado.

Cómo ejecutar

Abrir Guia de laboratorio 11/index.html en un navegador web.

Conclusión

El proyecto permite observar cómo las características de CSS moderno y las reglas de compatibilidad ayudan a mantener una presentación funcional entre navegadores.
