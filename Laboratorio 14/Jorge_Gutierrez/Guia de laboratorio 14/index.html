Lecturas de los talleres

Diseño responsivo

El diseño responsivo permite que el contenido de una página web se organice y adapte a diferentes tamaños de pantalla. Bootstrap utiliza un sistema de rejilla de doce columnas para distribuir los elementos de manera flexible.

Componentes reutilizables

Los componentes de Bootstrap permiten construir interfaces mediante estructuras reutilizables. Las tarjetas, botones y elementos de navegación ayudan a mantener una presentación consistente y organizada.

Acceso y mantenimiento

La accesibilidad permite que diferentes personas puedan utilizar una página web. Es importante mantener un foco visible, utilizar etiquetas adecuadas y comprobar que los elementos interactivos funcionen correctamente.

Variables CSS y temas

Las variables CSS permiten almacenar valores reutilizables, como colores, tamaños y espacios. Bootstrap utiliza variables para personalizar componentes y modificar sus estados visuales, como reposo, hover y pulsación, sin editar directamente sus archivos originales.

Criterios de entrega

  1. Comprueba el catálogo en tres anchos de pantalla.
  2. Recorre el menú, los enlaces y el diálogo utilizando el teclado.
  3. Explica una decisión de diseño con evidencia.
