Lecturas de los talleres

Diseño responsivo

El sistema de rejilla divide el espacio en doce unidades. Las clases col-12, col-md-6 y col-lg-4 permiten mostrar una, dos o tres columnas según el ancho disponible.

Componentes reutilizables

Una tarjeta repetible conserva jerarquía, separación y enlaces. Las clases card, card-body, h-100 y d-flex flex-column ayudan a mantener una composición uniforme.

Acceso y mantenimiento

El foco visible permite reconocer qué control está seleccionado al navegar con teclado. También es importante comprobar las rutas, los identificadores únicos y que el contenido siga siendo legible con zoom.

Variables CSS y temas

Las variables CSS permiten centralizar valores reutilizables. En este proyecto, --bs-btn-bg y --bs-btn-border-color definen el color normal del botón; las variables --bs-btn-hover-* cambian su apariencia al pasar el puntero y --bs-btn-active-* durante la pulsación. Así se crea una paleta coherente sin modificar bootstrap.min.css.

Criterios de entrega

  1. Comprueba el catálogo en tres anchos: 360, 800 y 1200 píxeles.
  2. Recorre el menú, los enlaces y el diálogo con teclado.
  3. Incluye el cuarto taller «Variables CSS y temas» y su lectura.
  4. Explica una decisión de diseño con evidencia de las pruebas.
